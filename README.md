# ITDA 잇다 · 한국수어 연습

국립국어원 한국수어사전의 시범을 보고 웹캠으로 따라 하는 학습 프로그램입니다. 목표 단어를 선택하면 동작 결과를 **O/X**와 **인식 점수(%)**로 확인할 수 있습니다.

## 실행 방법

### Windows에서 바로 열기

1. GitHub에서 **Code → Download ZIP**을 눌러 내려받고 압축을 풉니다. Git으로 받은 경우에는 내려받은 프로젝트 폴더를 엽니다.
2. `web` 폴더 옆에 있는 **`Start-ITDA.cmd`**를 더블클릭합니다. 한국수어 연습 화면이 기본 브라우저에서 열립니다.
3. 연습하는 동안 실행 창을 열어 둡니다. 실행 창을 닫으면 서버가 종료됩니다.

Windows 기본 PowerShell로 실행되며 Python 설치는 필요하지 않습니다. 단어 10개가 자동으로 표시됩니다. 시범 영상은 한국수어사전에서 불러오므로 인터넷 연결이 필요합니다.

### 터미널에서 직접 실행하기

웹캠이 있는 컴퓨터에서 저장소를 내려받고 압축을 풉니다. `README.md`와 `web` 폴더가 보이는 위치에서 터미널을 열고 다음 명령을 실행합니다.

```sh
python -m http.server 8000 --bind 127.0.0.1 --directory web
```

Windows에서 `python` 명령으로 실행되지 않으면 `py -m http.server 8000 --bind 127.0.0.1 --directory web`을 사용해 보세요.

### Windows PowerShell에서 Python 경로를 직접 지정하는 방법

Python 3.13이 사용자 기본 경로에 설치되어 있다면, `web` 폴더가 보이는 프로젝트 폴더에서 PowerShell을 열고 아래 명령으로 실행할 수 있습니다.

```powershell
& "$env:LOCALAPPDATA\Programs\Python\Python313\python.exe" -m http.server 8000 --bind 127.0.0.1 --directory web
```

터미널을 열어 둔 상태에서 [한국수어 연습 시작](http://127.0.0.1:8000/)을 눌러 브라우저에서 프로그램을 엽니다.

## 연습 방법

1. 연습할 단어를 선택하고 국립국어원 한국수어사전의 시범 영상을 봅니다. 영상 재생에는 인터넷 연결이 필요합니다.
2. **카메라 켜기**를 누르고 브라우저의 카메라 권한을 허용합니다. 왼손은 노란색, 오른손은 민트색 점과 선으로 표시됩니다.
3. **연습 시작**을 누르고 준비 시간이 끝나면 동작을 한 번 따라 합니다.
4. 인식 점수가 90% 이상이면 **O**, 그보다 낮으면 **X**가 표시됩니다. 손이 화면 밖으로 나가거나 동작을 충분히 포착하지 못하면 결과 표시를 보류하고 재시도를 안내합니다.

카메라 영상과 동작 판정은 브라우저 안에서 처리됩니다. 화면에 표시되는 인식 점수는 한 번의 동작에 대한 값입니다. 신규 사용자 대상의 웹캠 정확도는 별도 검증이 필요합니다.
